# Calibration Reference and Fault Injection Protocol

Line 1: Reference standards for acoustic emission coupling consistency.
Line 2: Acoustic couplant must be applied with controlled pressure of 5 N.
Line 3: Accelerometer stud torque must be calibrated to 2.5 Nm (+/- 0.2 Nm).
Line 4: Signal-to-noise ratio must exceed 6 dB for reliable peak identification.
Line 5: Sampling rate must be at least 200 kS/s to capture ultrasonic bursts up to 100 kHz.
